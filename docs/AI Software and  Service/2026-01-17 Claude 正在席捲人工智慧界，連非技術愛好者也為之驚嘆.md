
## 開發者和愛好者將Anthropic公司的Claude Code的爆紅與生成式人工智慧的問世相提並論。


[布拉德利·奧爾森](https://www.wsj.com/news/author/bradley-olson)

- 與去年同期相比，Claude 的網站總受眾在 12 月增長了一倍多，與上個月相比，全球每日獨立桌面訪客數量同比增長了 12%。
    
- 人工智慧能夠自主運行並廣泛存取用戶文件和應用程序，這預示著各個領域可能會出現功能更強大的人工智慧「代理」。

他們稱之為「被克勞德迷惑」。

在這一刻，軟體工程師、高管和投資者將他們的工作交給 Anthropic 公司的 Claude AI——然後見證了一台思維能力驚人的機器，即使在人工智慧工具層出不窮的時代也是如此。

許多程式設計師在假期都沉迷於“Claude 測試”，體驗 Anthropic 最新型號 Claude Opus 4.5 的各項功能。他們使用一款名為 Claude Code 的桌面編碼工具來測試這款模型。多年來，科技公司一直在將程式碼編寫人工智慧融入工作流程中，而先前的模型通常與初級軟體開發人員進行比較。但 Claude 最新版本引發的熱議卻截然不同。

馬爾特·烏布爾是Vercel公司的首席技術官，該公司為Claude Code和其他類似工具的用戶開發和託管網站及應用程式。他表示，他利用這款工具在一周內完成了一個複雜的項目，如果沒有人工智慧，他可能需要一年左右的時間才能完成。烏布爾在假期裡每天花10個小時開發新軟體，他說每次運行都讓他感到興奮，就像在拉斯維加斯玩老虎機一樣。

本月，Claude Code 的熱潮迅速蔓延，甚至吸引了非工程師群體。許多人在社群媒體上分享了他們如何在從未學習過程式設計的情況下，建立自己的第一個軟體程式。儘管名稱中帶有「代碼」二字，但人們使用 Claude Code 的用途卻十分廣泛，從健康數據分析到費用報表編制，無所不包。

有些人表示，他們先是感到敬畏，隨後又感到悲傷，因為他們意識到，這個計畫很容易就能複製他們整個職業生涯中累積的專業知識。

「這太神奇了，但也太可怕了，」加密貨幣稅務平台Awaken Tax的執行長安德魯杜卡說。杜卡從中學就開始學習程式設計。 “我畢生都在培養這項技能，結果克勞德·科德卻一舉摧毀了我的所有努力。” 

Anthropic 經常與 OpenAI 並駕齊驅。這兩家領先的 AI 模型新創公司都虧損數十億美元，但它們[專注於不同的市場](https://www.wsj.com/tech/ai/openai-anthropic-profitability-e9f5bcd6?mod=article_inline)。 OpenAI 擁有廣泛的全球消費者用戶群，用戶總數遠高於 Anthropic，而 Anthropic 則專注於企業客戶。根據 Menlo Ventures 的數據，截至 2025 年年中，Anthropic 在企業用戶市場佔有更大的份額。

近來，這兩家人工智慧新貴都黯然失色，而谷歌憑藉其令人印象深刻的人工智慧模型和工具套件[，在競爭中遙遙領先](https://www.wsj.com/tech/ai/google-ai-openai-gemini-chatgpt-b766e160?mod=article_inline)。但這並沒有阻止業內人士密切關注Anthropic的最新產品。

根據市場情報公司 Similarweb 和 Sensor Tower 的數據顯示，Claude 的網站總受眾在 12 月比上年同期增長了一倍多，其桌面端的每日獨立訪客數量今年迄今為止在全球範圍內比上個月增長了 12%。

杜卡說他原本計劃在公司招募新的軟體工程師，但後來決定放棄。他認為克勞德·科德讓他的工作效率提高了五倍。

與目前廣泛使用的大多數基於應用程式或網頁的聊天機器人不同，Claude Code 可以自主運行，並擁有廣泛的用戶文件、網路瀏覽器和其他應用程式存取權限。儘管技術專家預測，人工智慧「代理」即將迎來一個能夠為人類完成幾乎任何事情的時代，但這一願景的實現卻進展緩慢。對許多使用者而言，使用 Claude Code 是他們首次與這類人工智慧互動，也讓他們對未來的發展方向有了初步的了解。

人們用它來分析聯邦經濟數據、從損壞的硬碟中恢復婚禮照片、從零開始建立新網站、回覆大量電子郵件或訂餐。 Shopify 執行長Tobias Lütke表示，他曾利用 X 開發軟體來分析他最近接受的核磁共振檢查結果。

Claude Code 的負責人Boris Cherny說：“有人把網路攝影機接上去，然後就看著他們的番茄苗生長。這和以前的人工智慧完全不同。”

由於許多非程式設計師使用者都嘗試使用，Cherny 和他的團隊決定推出一個名為 Cowork 的衍生版本。與核心應用類似 MS-DOS 的「命令列」介面不同，Cowork 採用了更友善的圖形使用者介面。他們使用 Claude Code 僅用了大約 10 天就開發了這款產品。

預計[今年上市的](https://www.wsj.com/tech/ai/anthropic-raising-10-billion-at-350-billion-value-62af49f4?mod=article_inline)Anthropic公司長期以來一直秉持著以精通人工智慧編碼為核心的策略，其次是「工具化」——即人工智慧系統在有限的人工幹預下使用不同軟體的能力。大多數基準測試長期以來都將其視為最佳編碼模型，[根據](https://gorilla.cs.berkeley.edu/leaderboard.html)加州大學柏克萊分校研究人員維護的基準測試，它也是領先的工具化模型。

許多人想知道接下來會發生什麼事。

「更值得關注的是，這項技術何時會超越軟體工程的範疇，」商業人工智慧新創公司Retool的執行長David Hsu說。軟體工程師在美國勞動力中只佔很小一部分。 “這項技術究竟能發展到什麼程度？”
