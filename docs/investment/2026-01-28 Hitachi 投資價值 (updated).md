- **資金排擠效應 (Crowding Out)：** 企業的 IT 預算是固定的。今年老闆說要搞 AI，錢全部拿去買 NVIDIA GPU 了。原本計畫要換新的日立儲存櫃？「先緩緩，舊的將就著用。」—— 這就是日立說的「Refraining from investment」。
    
- **上雲趨勢 (Cloud Shift)：** 越來越多企業不再自己買儲存設備放機房，而是直接把資料丟到 AWS S3 或 Azure Blob。這直接殺死了日立 Vantara 的硬體銷量。
    

#### 3. 遇到更強的對手了嗎？ (The Competitive Loss)

**是的，日立正在失去市佔率。**

- **價格破壞者：** **Dell (戴爾) 和 HPE**。他們的規模比日立大得多，採購硬碟的成本更低，可以用更便宜的價格搶單。
